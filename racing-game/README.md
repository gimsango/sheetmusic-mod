# 🏁 터보 카트 3D

브라우저에서 돌아가는 3D 카트 레이싱 게임 (Three.js).

- **맵 1,000개** — 번호마다 시드로 생성되는 고유 코스(길이·커브·고저차·뱅킹) + 10가지 테마(숲/사막/설원/네온 시티/화산/열대 해변/단풍/캔디/우주 기지/석양 협곡) × 각 100종
- **카트 100,000종** — 차체 20 × 페인트 20 × 휠 25 × 윙/파츠 10 조합, 파츠마다 스탯(속도/가속/핸들링/드리프트)이 달라짐
- **WiFi 멀티플레이** — 같은 WiFi(LAN)의 폰/PC/태블릿이 브라우저로 접속, 방 코드로 입장 (최대 12명, 호스트가 AI 봇 추가 가능)
- 드리프트 미니터보(파랑→주황→보라), 부스트 패드, 벽/갓길 판정, AI 상대, 미니맵, 블룸/그림자, 엔진음(WebAudio), 터치·키보드·게임패드

## 실행
```bash
cd racing-game
npm install
npm start          # 기본 포트 3000 (PORT=3123 npm start 로 변경)
```
서버가 출력하는 `WiFi/LAN : http://192.168.x.x:3000` 주소를 같은 WiFi의 기기에서 열면 됩니다.
한 명이 **WiFi 멀티플레이 → 방 만들기**, 나머지는 **4자리 방 코드**로 입장합니다.
(방화벽에서 해당 포트를 허용해야 할 수 있습니다.)

## 조작
| 키 | 동작 |
|---|---|
| ↑/W, ↓/S, ←→/AD | 가속, 브레이크/후진, 조향 |
| Space / Shift | 드리프트 (코너에서 누른 채 유지 → 떼면 부스트) |
| R / M / Q / Esc | 트랙 복귀 / 음소거 / 그래픽 품질 / 일시정지 |

모바일은 화면 버튼, 게임패드는 왼쪽 스틱 + RT/LT/RB 지원.

## 구조
- `server.js` — 정적 파일 + WebSocket 방/상태 중계 서버
- `public/js/track.js` — 절차적 트랙·테마·장식물·하늘 생성
- `public/js/karts.js` — 10만 종 카트 조합/모델/스탯
- `public/js/physics.js` — 아케이드 물리, 드리프트, AI
- `public/js/main.js` — 렌더링, UI, 레이스 루프, 멀티플레이 클라이언트

카트 번호 N(1~100000) → `body=(N-1)%20, paint=⌊(N-1)/20⌋%20, wheel=⌊(N-1)/400⌋%25, wing=⌊(N-1)/10000⌋` 로 디코딩됩니다.
