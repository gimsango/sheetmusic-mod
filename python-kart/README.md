## 공통 기능
- **맵 1,000개 = 바이옴 1,000종** : 번호(1~1000)마다 고유 코스(길이 1.5~5 km, 커브, 오르내림, 뱅킹) + **맵마다 서로 다른 바이옴**
  (생태계 40가지 × 시간대 5가지 × 색감 5가지 — 하늘·지평선·땅·장식물·날씨·조명이 모두 달라짐). 아래 설명 참고
- **카트 100,000종** : 차체 20 × 페인트 20 × 휠 25 × 윙/파츠 10 조합 (파츠마다 속도·가속·핸들링·드리프트 수치가 다름). 차고에서 번호로도 선택
- **아이템전 · 아이템 100종** : 트랙 위 무지개 **아이템 상자**를 지나가면 아이템을 얻고, **1 · 2 · 3 번 키**(폰은 화면 위 칸 터치)로 사용 — 아래 설명 참고
- **WiFi(LAN) 멀티플레이** : 최대 12명, 방장이 모드(아이템전/스피드전)/맵/바퀴 수/AI 봇 수 설정, 방 자동 검색 또는 IP 직접 입력
- 드리프트 미니터보(파랑→주황→보라), 부스트 패드, 벽·갓길 판정, 순위/랩타임, 미니맵, AI 상대, 효과음(코드로 합성)

## 🌍 바이옴 1000종 (모든 맵이 서로 다른 환경)
맵 번호마다 **그 맵만의 바이옴**이 정해집니다. 바이옴 = **생태계 40가지 × 시간대 5가지 × 색감 5가지 = 1000가지**이고,
1000개 맵이 모두 다른 조합이라 이름도 전부 다릅니다 (예: `숲 (아침)`, `에메랄드 대나무 숲 (안개)`, `서리 내린 숲 (노을)`, `푸른 네온 시티 (오로라)`).
- **생태계**마다 지평선(산맥·사구·도시 스카이라인·화산·바다·메사·수정 첨탑·구름섬·유적·공장·신스웨이브 등 20종 이상),
  땅/도로/벽/연석 색, 장식물(나무·야자수·대나무·거대 버섯·산호·풍차·피라미드·묘비·호박·굴뚝·돔 기지 등 **32종**), 날씨가 다릅니다.
- **시간대**: 새벽녘 · 아침 · 한낮 · 황금빛 오후 · 노을 · 황혼 · 달밤 · **오로라** · 흐린 날 · 폭풍우 · 안개 (+ 우주 계열은 성운 하늘, 해저 계열은 바닷속 빛)
- **색감**: 기본 · 황금빛 · 붉은 · 푸른 · 보랏빛 · 에메랄드 · 서리 내린(눈 덮인 나무) · 어둠의 · 파스텔 · 잿빛 · 선명한 · 장밋빛 · 호박색 · 비취빛 · 은빛
- **날씨 12종**: 눈 · 비 · 불씨 · 재 · 낙엽 · 꽃잎 · 포자 · 반딧불 · 거품(해저) · 반짝이 · 먼지 · 스프링클
- 같은 맵 번호는 어느 기기에서나 같은 바이옴이라 **멀티플레이에서도 모두 같은 풍경**을 봅니다.
- **고르는 법**: 폰은 맵 선택 화면 아래 `생태계 < >`, `시간대 < >`, `색감 < >` 버튼 / PC 는 솔로 메뉴의 `바이옴 · 시간대 · 색감` 줄(←→), `T` 키는 다음 생태계.

## 🎁 아이템전 (아이템 100종)
솔로 레이스 설정과 멀티플레이 로비에서 **스피드전 / 아이템전**을 고를 수 있습니다 (기본: 아이템전).

| 조작 | 폰 (터치) | 키보드 (PC / 폰 버전을 PC 에서) | 게임패드 (PC) |
|---|---|---|---|
| 슬롯 1 · 2 · 3 아이템 사용 | 화면 **위쪽 아이템 칸**을 누르기 | **1 · 2 · 3** | X · Y · B |
| 뒤로 던지기 (미사일·폭탄 등) | 브레이크를 누른 채 칸 누르기 | **↓ 를 누른 채** 1 · 2 · 3 | LT 누른 채 |

- 아이템 칸은 **3개**. 상자를 먹으면 빈 칸에 룰렛이 돌고, 멈추면 이름과 효과가 화면에 나옵니다. 칸마다 번호(1·2·3)가 붙어 있어요.
- **x3** 표시는 여러 번 쓸 수 있는 아이템 (트리플 미사일, 황금 부스터 x7 …).
- **순위에 따라 나오는 아이템이 달라요.** 1등 근처는 방어/함정 위주, 뒤처질수록 로켓·1등 추적 미사일·번개 같은 강한 아이템이 잘 나옵니다.
- 맞으면 **스핀 / 날아감 / 축소 / 감속 / 미끄러짐 / 빙결 / 엔진 정지 / 조작 반전 / 시야 가림(먹물)** 등의 효과. 방패·무적·유령·점프로 피할 수 있습니다.
- 나를 노리는 유도 미사일·1등 추적 미사일·메테오가 날아오면 **"! 미사일 접근 !"** 경고가 뜹니다.
- AI 봇들도 상황을 보고 아이템을 씁니다 (앞에 차가 있으면 발사, 뒤에 붙으면 함정, 직선에서 부스터 …).
- 멀티플레이에서도 상자·발사체·함정·명중·훔치기·자리 바꾸기가 모든 기기(폰+PC)에 동기화됩니다.

## 📱 폰: Pydroid 3 에서 실행 (`kart3d_phone.py`)
1. Play 스토어에서 **Pydroid 3** 설치
2. Pydroid 3 왼쪽 메뉴 → **Pip** → `pygame` 검색 → **설치**
3. `kart3d_phone.py` 를 폰에 저장 → Pydroid 3 에서 **폴더 아이콘(Open)** 으로 열기 → **▶ 실행**
   (또는 파일 내용을 통째로 복사해서 새 파일에 붙여넣기)
4. **가로 모드**를 추천합니다. 조작은 화면 버튼: ◀ ▶ 조향 · **DRIFT** · 브레이크 (가속은 기본 **자동**, 설정에서 끌 수 있음)

**팁**
- 패키지가 없으면 게임이 설치 방법을 화면에 알려줍니다. (PC 에서는 *y* 를 누르면 같은 파이썬으로 자동 설치 후 바로 시작)
- 프레임이 낮으면 *설정 → 그래픽 품질*을 낮춤으로. (게임이 느려지면 자동으로도 낮춰줍니다)
- 한글이 네모로 보이면 같은 폴더에 한글 TTF 를 `kart3d_font.ttf` 이름으로 두세요. (폰트를 못 찾으면 자동으로 영어 UI)
- PC 에서도 `python kart3d_phone.py` 로 실행됩니다 (키보드: ←→ 조향, ↑ 가속, ↓ 브레이크, Space 드리프트, **1·2·3 아이템**, R 복귀, Esc 일시정지)
- 아이템전에서는 화면 위 가운데의 **아이템 칸 3개**를 손가락으로 눌러 사용합니다.

## 📡 WiFi 멀티플레이 하는 법
1. 모두 **같은 WiFi** (또는 한 명의 폰 핫스팟)에 연결합니다.
2. 한 명이 **멀티플레이 → 방 만들기(호스트)**. 화면에 **IP 주소**가 나옵니다 (예: `192.168.0.5:5555`).
3. 나머지는 **멀티플레이** 화면에서 방이 자동으로 뜨면 선택하거나, **IP 직접 입력**으로 참가합니다.
4. 방장이 **모드(아이템전/스피드전)**·맵·바퀴 수·AI 봇 수를 정하고 **레이스 시작!**
- 폰 + 폰, 폰 + PC, PC + PC 어떤 조합이든 같은 방에 들어갈 수 있습니다.
- 전용 서버(방장 없이): `python kart3d_pc.py --serve` 또는 `python kart3d_phone.py --serve`
- 접속이 안 되면: PC 방화벽에서 **TCP 5555 / UDP 5556** 허용, 공유기의 *AP(클라이언트) 격리* 기능 끄기.
  방 자동 검색이 막힌 네트워크에서는 IP 직접 입력을 쓰세요.

## 문제 해결
- **파일을 더블클릭하면 검은 창이 떴다가 바로 사라져요** → 오류를 볼 수 있게 이렇게 실행하세요.
  게임 파일이 있는 폴더를 연 뒤 **주소창에 `cmd` 입력 → Enter** → 검은 창에서 `python kart3d_pc.py` (안 되면 `py kart3d_pc.py`).
  (최신 버전은 오류가 나도 창이 바로 닫히지 않고, 오류 내용을 같은 폴더의 `kart3d_error.txt` 에도 저장합니다)
- **조작감이 이상해요 (차가 갑자기 느려지거나, 조향이 굼떠요)** → 최신 파일로 바꿔서 실행하세요.
  PC 에서 `kart3d_phone.py` 를 키보드로 할 때, ← → 를 누르면 자동 가속이 꺼지던 문제를 고쳤습니다. (↑ 를 한 번 눌러 보면 그때부터 직접 가속 모드)
  *설정 → 조향 반응* (부드럽게 / 보통 / 빠르게) 으로 키보드·버튼 조향 속도를 바꿀 수 있습니다.
- **반응속도가 느려요** → 최신 버전에서 조향이 더 빨리 반응하고(보통 기준 0.22초에 최대 조향), 미끄러짐이 줄고, 카메라도 더 빨리 따라옵니다.
  PC(Panda3D) 버전은 화면 글자를 매 프레임 다시 만들던 부분을 고쳐서 프레임이 더 안정적입니다. 그래도 느리면 *설정 → 조향 반응 → 빠르게*.
- **`pygame` 설치가 `distutils`/`msvccompiler` 오류로 실패해요 (Python 3.14/3.15)** → 너무 새로운 파이썬이라 `pygame` 설치 파일이 없는 경우입니다.
  `pip install pygame-ce` (같은 `import pygame` 으로 쓰는 호환 버전)로 해결됩니다. 최신 폰 버전 파일은 이걸 자동으로 시도합니다.
  `panda3d` 는 파이썬 3.14 까지만 설치되므로, GPU 버전을 쓰려면 **Python 3.13** 을 추가로 설치하세요 (지금 파이썬은 그대로 둬도 됩니다).
  명령 창에서 `py install 3.13` (안 되면 python.org 에서 3.13 설치, "Add python.exe to PATH" 체크).
  **설치한 뒤에는 `kart3d_pc.py` 를 그냥 다시 실행하세요.** 게임이 설치된 다른 파이썬(3.13 등)을 스스로 찾아서 `panda3d` 를 설치하고, 그 파이썬으로 자동 재시작합니다.
  (직접 하려면: `py -3.13 -m pip install panda3d` → `py -3.13 "kart3d_pc (2).py"` — 파일 이름에 공백/괄호가 있으면 따옴표로 감싸고, 가능하면 `kart3d_pc.py` 로 이름을 바꾸세요)
- **`panda3d`/`pygame` 이 필요하다고 나와요** → 위 설치 방법 참고. 게임이 올바른 설치 명령을 보여 주고, PC 에서는 **y** 로 자동 설치도 됩니다.
- 폰에서는 `kart3d_pc.py` 가 아니라 **`kart3d_phone.py`** 를 실행하세요.

```
│  ├─ pc/               ← PC 프론트엔드 (Panda3D)
│  └─ build.py          ← core + 프론트엔드를 합쳐 단일 .py 생성:  python3 src/build.py
└─ tests/               ← 헤드리스 테스트 (코어/렌더링/UI/멀티플레이/퍼징)
```
- 맵 번호 N → 시드 해시 → 바이옴(생태계 `(N-1)%40`, 변형 `(N-1)//40` → 시간대·색감)/이름/코스. 카트 번호 K(0~99999) → `body=K%20, paint=⌊K/20⌋%20, wheel=⌊K/400⌋%25, wing=⌊K/10000⌋`
- 프로토콜: TCP 줄 단위 JSON (`join/settings/start/s/b/fin/lobby`), 방 검색은 UDP 브로드캐스트(`KART3D?`)
- 아이템전 메시지(`i*`): `ib` 상자 획득, `iu` 사용(발사체/함정 생성), `ih` 명중/소멸, `ia` 광역 효과·훔치기·자리 바꾸기, `ig` 훔친 아이템 전달.
  맞았는지는 **맞은 카트를 시뮬레이션하는 기기**(내 카트는 내 기기, 봇은 방장)가 판정해서 알립니다. 상태 효과는 `s`/`b` 메시지의 `fx` 비트로 전달.
- 아이템 표/아이콘(벡터)/효과는 `src/core/09_items.py` 하나에 있고, 두 프론트엔드가 같은 정의로 그립니다.
- 바이옴(생태계·시간대·색감·날씨·장식물 비율)과 360도 지평선 정의는 `src/core/02_biome.py` 에 있고, 폰(2D 파노라마)과 PC(원통 메시)가 같은 정의로 그립니다.
