# 🏁 TURBO KART 3D — 파이썬 버전 (폰 / PC)

3D 카트 레이싱 게임을 **파이썬**으로 만든 두 가지 버전입니다. 둘 다 **파일 하나**만 실행하면 되고,
**폰 버전과 PC 버전이 같은 WiFi 방에서 함께 달릴 수 있습니다.**

| 파일 | 대상 | 렌더링 | 필요한 것 |
|---|---|---|---|
| `kart3d_phone.py` | 📱 **Pydroid 3** (안드로이드) — PC에서도 실행 가능 | pygame 으로 직접 만든 **소프트웨어 3D** (순수 파이썬) | `pygame` |
| `kart3d_pc.py` | 💻 **컴퓨터(Windows/Mac/Linux)** | **Panda3D GPU 3D** (조명·안개·텍스처·하늘) | `panda3d` |

## 공통 기능
- **맵 1,000개** : 번호(1~1000)마다 시드로 생성되는 고유 코스(길이 1.5~5 km, 커브, 오르내림, 뱅킹) + 10가지 테마
  (숲 · 사막 · 설원 · 네온 시티 · 화산 · 열대 해변 · 단풍 · 캔디 월드 · 우주 기지 · 석양 협곡) × 100종. 맵마다 이름/장식물/부스트 패드 배치가 다름
- **카트 100,000종** : 차체 20 × 페인트 20 × 휠 25 × 윙/파츠 10 조합 (파츠마다 속도·가속·핸들링·드리프트 수치가 다름). 차고에서 번호로도 선택
- **WiFi(LAN) 멀티플레이** : 최대 12명, 방장이 맵/바퀴 수/AI 봇 수 설정, 방 자동 검색 또는 IP 직접 입력
- 드리프트 미니터보(파랑→주황→보라), 부스트 패드, 벽·갓길 판정, 순위/랩타임, 미니맵, AI 상대, 효과음(코드로 합성)

## 📱 폰: Pydroid 3 에서 실행 (`kart3d_phone.py`)
1. Play 스토어에서 **Pydroid 3** 설치
2. Pydroid 3 왼쪽 메뉴 → **Pip** → `pygame` 검색 → **설치**
3. `kart3d_phone.py` 를 폰에 저장 → Pydroid 3 에서 **폴더 아이콘(Open)** 으로 열기 → **▶ 실행**
   (또는 파일 내용을 통째로 복사해서 새 파일에 붙여넣기)
4. **가로 모드**를 추천합니다. 조작은 화면 버튼: ◀ ▶ 조향 · **DRIFT** · 브레이크 (가속은 기본 **자동**, 설정에서 끌 수 있음)

**팁**
- 프레임이 낮으면 *설정 → 그래픽 품질*을 낮춤으로. (게임이 느려지면 자동으로도 낮춰줍니다)
- 한글이 네모로 보이면 같은 폴더에 한글 TTF 를 `kart3d_font.ttf` 이름으로 두세요. (폰트를 못 찾으면 자동으로 영어 UI)
- PC 에서도 `python kart3d_phone.py` 로 실행됩니다 (키보드: ←→ 조향, ↑ 가속, ↓ 브레이크, Space 드리프트, R 복귀, Esc 일시정지)

## 💻 PC: `kart3d_pc.py`
```bash
pip install panda3d          # 한 번만
python kart3d_pc.py          # 옵션: --window 1600x900  --fullscreen  --lang en  --fps
```
| 키 | 동작 |
|---|---|
| ↑/W · ↓/S · ←→/AD | 가속 · 브레이크/후진 · 조향 |
| Space / Shift | 드리프트 (코너에서 누른 채 유지, 떼면 부스트) |
| R · Esc · M · F11 | 트랙 복귀 · 일시정지 · 소리 · 전체화면 |
| 게임패드 | 왼쪽 스틱 + RT/LT + A(드리프트) |

메뉴: ↑↓ 선택, ←→ 값 변경(Shift ±10, Ctrl ±100), Enter 확인, Esc 뒤로.
Panda3D 설치가 안 되는 환경이면 `kart3d_phone.py` 를 PC 에서 실행해도 됩니다.

## 📡 WiFi 멀티플레이 하는 법
1. 모두 **같은 WiFi** (또는 한 명의 폰 핫스팟)에 연결합니다.
2. 한 명이 **멀티플레이 → 방 만들기(호스트)**. 화면에 **IP 주소**가 나옵니다 (예: `192.168.0.5:5555`).
3. 나머지는 **멀티플레이** 화면에서 방이 자동으로 뜨면 선택하거나, **IP 직접 입력**으로 참가합니다.
4. 방장이 맵·바퀴 수·AI 봇 수를 정하고 **레이스 시작!**
- 폰 + 폰, 폰 + PC, PC + PC 어떤 조합이든 같은 방에 들어갈 수 있습니다.
- 전용 서버(방장 없이): `python kart3d_pc.py --serve` 또는 `python kart3d_phone.py --serve`
- 접속이 안 되면: PC 방화벽에서 **TCP 5555 / UDP 5556** 허용, 공유기의 *AP(클라이언트) 격리* 기능 끄기.
  방 자동 검색이 막힌 네트워크에서는 IP 직접 입력을 쓰세요.

## 개발자용
```
python-kart/
├─ kart3d_phone.py      ← 빌드 결과(단일 파일) — Pydroid 3 용
├─ kart3d_pc.py         ← 빌드 결과(단일 파일) — PC 용
├─ src/
│  ├─ core/             ← 공통 코어: 맵/트랙 생성, 카트 파츠, 물리, AI, 레이스, 네트워크, 프로필
│  ├─ phone/            ← 폰 프론트엔드 (pygame 소프트웨어 3D + 터치 UI)
│  ├─ pc/               ← PC 프론트엔드 (Panda3D)
│  └─ build.py          ← core + 프론트엔드를 합쳐 단일 .py 생성:  python3 src/build.py
└─ tests/               ← 헤드리스 테스트 (코어/렌더링/UI/멀티플레이/퍼징)
```
- 맵 번호 N → 시드 해시 → 테마(`(N-1)%10`)/이름/코스. 카트 번호 K(0~99999) → `body=K%20, paint=⌊K/20⌋%20, wheel=⌊K/400⌋%25, wing=⌊K/10000⌋`
- 프로토콜: TCP 줄 단위 JSON (`join/settings/start/s/b/fin/lobby`), 방 검색은 UDP 브로드캐스트(`KART3D?`)
- 웹 브라우저 버전(`../racing-game`, Node.js + Three.js)도 함께 들어 있습니다.
