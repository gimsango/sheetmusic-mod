# 악보 모드 (Sheet Music) - Fabric 1.20.1

## 사용법
- **악보**: 종이 + 먹물 주머니 + 깃털 (조합법). 창작 탭 "악보 모드"에도 있음.
- **피아노**: 나무 판자 8개 + 노트 블록 (가운데). 창작 탭에도 있음.
- 악보를 들고 **우클릭** → 책 모양 작곡 화면이 열립니다. (피아노를 바라보고 있다면 **웅크리고(Shift)** 우클릭)
  - 오른쪽 페이지: 16칸 x 25음(2옥타브, F#3~F#5) 피아노 롤. 좌클릭 = 음 넣기/빼기, 우클릭 = 그 칸 비우기
  - 한 칸에 여러 음을 찍으면 화음. 페이지는 최대 8장(128칸)
  - 왼쪽 페이지: 제목, BPM(+/-), 페이지 이동, 미리듣기, 페이지 지우기, 완료
  - 화면을 닫으면 자동 저장됩니다.
- 악보를 들고 **피아노를 우클릭** → 악보대로 연주. 빈 손으로 우클릭 → 정지.

## 빌드
1. JDK 17 설치
2. 이 폴더에서 `gradle build` (Gradle 8.x) 또는 IntelliJ에서 폴더를 Gradle 프로젝트로 열기
3. `build/libs/sheetmusic-1.0.0.jar` 을 mods 폴더에 넣기
   (Fabric Loader 0.14.21+ / Fabric API 0.92.2+1.20.1 필요)
